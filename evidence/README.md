# Evidence Checklist

The case study explicitly asks for proof that real products landed on Fynd. Do not fake this section.

After running `npm run ingest` against your development company, add:

1. `products-created.png` - Fynd platform product listing showing the Northwind SKUs.
2. `product-detail.png` - One product detail page showing variants/images/price.
3. `api-success-response.json` - Redacted successful create-product response.
4. `validation-report.md` - Copy of `reports/validation-report.md` showing the invalid rows and edge-case handling.

Recommended screenshots:

- `NW-TSH-001` with sizes `S`, `M`, `L`
- `NW-CHN-101` with sizes `32`, `34`, `36`
- `NW-ACC-010` as `One Size`

Redact tokens, API secrets, cookies, and account identifiers before committing.
